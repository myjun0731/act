# mobile

- **opt-in**: allinone에 포함되지 않는다. 필요할 때만 `claude plugin install mobile@act`로 설치한다.
- **독립 동작**: ECC 하네스(커맨드·에이전트·훅·메모리) 없이 동작하도록 고쳐서 넣는다. `python scripts/check_skills.py --plugin mobile`이 ERROR 0이어야 한다.
